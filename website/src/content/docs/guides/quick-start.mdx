---
title: 快速开始
description: 用一条 Docker 命令启动 KinGei。
---

import { Steps, Aside } from '@astrojs/starlight/components';

需要已安装 [Docker](https://docs.docker.com/get-docker/)。

<Steps>

1. 启动

   ```bash
   docker run -d --name kingei --restart unless-stopped -p 3000:3000 -v ./KinGei-data:/kingei-data ghcr.io/flattered8256/kingei:latest
   ```

2. 打开站点

   浏览器访问服务器 3000 端口。

3. 注册管理员

   首次注册的账号为管理员。

</Steps>

<Aside>
数据写在当前目录的 `KinGei-data/`，包括数据库、上传文件和 JWT。备份或迁移时带走整个目录。
</Aside>

## 更新

```bash
docker pull ghcr.io/flattered8256/kingei:latest
docker rm -f kingei
docker run -d --name kingei --restart unless-stopped -p 3000:3000 -v ./KinGei-data:/kingei-data ghcr.io/flattered8256/kingei:latest
```


需要从源码构建，见 [docker 部署](../docker/)。

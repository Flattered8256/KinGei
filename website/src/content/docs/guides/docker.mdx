import { Tabs, TabItem, Aside } from '@astrojs/starlight/components';

<Aside type="tip">
只想用官方镜像跑起来，见 [快速开始](../quick-start/)。
</Aside>

## 1. 克隆仓库

```bash
git clone https://github.com/Flattered8256/KinGei.git
cd KinGei
```

## 2. 准备环境变量

```bash
cp .env.example .env
```

编辑：

| 变量 | 说明 |
| --- | --- |
| `PORT` | 端口，默认 `3000` |


## 3. 启动

<Tabs>
<TabItem label="本地磁盘" icon="laptop">

```bash
docker compose up -d --build
```

</TabItem>
<TabItem label="S3" icon="cloud-download">

```bash
docker compose -f docker-compose.yml -f docker-compose.s3.yml up -d --build
```

</TabItem>
<TabItem label="PostgreSQL" icon="database">

```bash
docker compose -f docker-compose.yml -f docker-compose.postgres.yml up -d --build
```

</TabItem>
<TabItem label="PostgreSQL + S3" icon="server">

```bash
docker compose -f docker-compose.yml -f docker-compose.s3.yml -f docker-compose.postgres.yml up -d --build
```

</TabItem>
</Tabs>

## 4. 注册管理员账号

浏览器访问服务器地址，端口默认 `3000`。

首次注册的账号为管理员。

## 更新

```bash
git pull

```
